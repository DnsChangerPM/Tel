# Tel — ویرایشگر متن تلگرام 🖊️

برنامه‌ای با **Flutter** برای باز کردن، ویرایش و ذخیرهٔ فایل‌های XML ترجمهٔ تلگرام
(مثل `tg_inline_strings.xml`) — همراه با ورک‌فلوی **GitHub Actions** که هنگام اجرا
**نسخهٔ برنامه را می‌پرسد** و دو خروجی می‌سازد و در بخش **Releases** منتشر می‌کند:

| خروجی | نوع فایل | سازگاری |
| --- | --- | --- |
| 📱 **APK** اندروید | نصب مستقیم روی گوشی | **اندروید ۷.۰ تا آخرین نسخهٔ اندروید** |
| 🖥️ **EXE** ویندوز | نسخهٔ پرتابل + فایل نصب (Setup) + zip | **ویندوز ۸.۱ تا ویندوز ۱۱** |

---

## ۱) چطور APK و EXE را بسازم؟ (بدون هیچ دانش فنی)

1. در گیت‌هاب به تب **Actions** بروید.
   > نکته: دکمهٔ **Run workflow** فقط وقتی در تب Actions دیده می‌شود که فایل
   > ورک‌فلو روی شاخهٔ پیش‌فرض (`main`) وجود داشته باشد. پس اگر تغییرها هنوز در
   > یک شاخهٔ دیگر (مثل Pull Request) هستند، اول آن‌ها را در `main` merge کنید.
2. ورک‌فلوی **«Build & Release (APK + EXE)»** را انتخاب کنید.
3. دکمهٔ **Run workflow** را بزنید.
4. در کادر **نسخه**، شمارهٔ نسخه را وارد کنید؛ مثلاً `1.2.0` یا `1.2.0+7`.
   (این همان نسخه‌ای است که داخل APK، داخل EXE و در نام فایل‌ها می‌آید.)
5. گزینهٔ **ساخت انتشار در بخش Releases** را روی `true` بگذارید.
6. **Run workflow** را بزنید و منتظر بمانید (حدود ۱۰ تا ۲۰ دقیقه).
7. تمام! به تب **Releases** بروید؛ این فایل‌ها آنجا هستند:

```
Tel-1.2.0-android.apk             ← نصب روی اندروید ۷ تا آخرین نسخه
Tel-1.2.0-setup-x64.exe           ← فایل نصب ویندوز ۸.۱ تا ۱۱ (اگر Inno Setup موجود باشد)
Tel-1.2.0-windows-x64.exe         ← نسخهٔ پرتابل ویندوز
Tel-1.2.0-windows-x64.zip         ← بستهٔ کامل پرتابل (exe + dll + data)
```

> **روش دوم (با تگ):** اگر ترجیح می‌دهید از خط فرمان بسازید:
> `git tag v1.2.0 && git push origin v1.2.0`
> همین ورک‌فلو با همان نسخه اجرا می‌شود و انتشار را می‌سازد.

### چرا برای ویندوز دو فایل مختلف منتشر می‌شود؟

خروجی ویندوزی Flutter از سه بخش تشکیل شده است: `tel.exe`، `flutter_windows.dll` و
پوشهٔ `data`. فایل `exe` به‌تنهایی و بدون آن دو بخش دیگر **اجرا نمی‌شود**؛ پس:

* برای نصب تمیز → `setup-x64.exe` (یا `zip` را باز کنید و `tel.exe` را اجرا کنید)
* اگر `exe` تک‌فایلی را جدا دانلود کردید، آن را کنار `flutter_windows.dll` و پوشهٔ
  `data` از فایل zip بگذارید.

## ۲) برنامه چه کاری انجام می‌دهد؟

فایل‌های ترجمهٔ تلگرام فایل‌های متنی XML هستند؛ مثلاً:

```xml
<resources>
    <string name="VoipGroupEnableAutoDelete">حذف خودکار پس از %1$d روز</string>
</resources>
```

**Tel** این فایل‌ها را باز می‌کند، همهٔ متن‌ها را فهرست می‌کند و اجازه می‌دهد
تک‌تک آن‌ها را ویرایش کنید و دوباره ذخیره کنید — **بدون آسیب به بقیهٔ فایل**.

### امکانات

* **تب متن فایل:** ویرایشگر XML با شمارهٔ خط/ستون و جست‌وجو و جایگزینی
  (با پشتیبانی Regular Expression و حساس/غیرحساس به بزرگی و کوچکی حروف).
* **تب رشته‌ها:** فهرست همهٔ `<string>`ها با فیلترهای «ترجمه‌نشده‌ها»،
  «ویرایش‌شده‌ها»، «خالی‌ها» و «فنی/غیرقابل‌ترجمه»؛ ویرایش هر متن به‌صورت زنده،
  نمایش قالب‌ها (`%1$s`، `%d`، `{0}`)، کپی سریع و برگشت تغییر.
* **تب بررسی سلامت:** تشخیص تگ‌های نامتوازن، `&` بدون escape، نام تکراری،
  مقدار خالی، رشته‌های ترجمه‌نشده و **ناسازگاری قالب‌ها** با فایل انگلیسی مرجع.
* **ذخیرهٔ بی‌خطر:** فقط مقدار رشته‌هایی که ویرایش کرده‌اید بازنویسی می‌شود؛
  کامنت‌ها، ترتیب، فاصله‌ها و خط‌های خالی فایل اصلی دست‌نخورده می‌مانند.
  خروجی **UTF-8 بدون BOM** است.
* **رابط دوزبانه:** فارسی (راست‌به‌چپ، پیش‌فرض) و انگلیسی؛ پوستهٔ تیره و روشن.
* **بدون هیچ وابستگی بیرونی:** انتخاب فایل روی اندروید با
  Storage Access Framework و روی ویندوز با دیالوگ بومی ویندوز (PowerShell) انجام
  می‌شود؛ یعنی هیچ پلاگین ثالثی در پروژه نیست.

### نکته‌های مهم ترجمه

* `\n` در این فایل‌ها **کاراکتر خط جدید** است؛ آن را حذف یا خراب نکنید.
* قالب‌هایی مثل `%1$s`، `%d`، `{0}` باید در متن ترجمه **دقیقاً** باقی بمانند.
* داخل مقدارها نمی‌توان `&` و `<` و `>` را خام نوشت؛ برنامه خودش هنگام ذخیره
  آن‌ها را به `&amp;`، `&lt;` و `&gt;` تبدیل می‌کند.

راهنمای کامل و بلند در `docs/TELEGRAM_XML_GUIDE.md` و داخل خود برنامه (تب «راهنما») هست.
راهنمای ورک‌فلو و عیب‌یابی ساخت در `docs/GITHUB_ACTIONS.md` است.

## ۳) سازگاری نسخه‌ها

| مورد | اندروید | ویندوز |
| --- | --- | --- |
| حداقل نسخه | **اندروید ۷.۰ (API 24)** | **ویندوز ۸.۱ (NT 6.3)** |
| آخرین نسخهٔ پشتیبانی‌شده | آخرین نسخهٔ اندروید (`targetSdk 36`) | ویندوز ۱۱ |
| معماری | arm64-v8a / armeabi-v7a / x86_64 (APK یونیورسال) | ۶۴ بیتی (x64) |
| Flutter ساخت | `3.47.5` | `3.19.6` |

**چرا ویندوز با Flutter قدیمی‌تر ساخته می‌شود؟**
Flutter از نسخهٔ 3.19 به بعد پشتیبانی ویندوز ۸.۱ (و ۷) را حذف کرده است؛
بنابراین برای اینکه خروجی روی ویندوز ۸.۱ هم اجرا شود، جاب ویندوز روی
`3.19.6` اجرا می‌شود. برای اینکه کد یکجا بماند، کل کد Dart در محدودهٔ
API های Flutter 3.19 نوشته شده و با هر دو نسخه کامپایل می‌شود
(`pubspec.yaml` → `sdk: >=3.3.0 <4.0.0` و `flutter: >=3.19.0`).

طبق اعلام رسمی تیم Flutter، «Dart 3.3 و Flutter 3.19 آخرین نسخه‌هایی هستند که از
ویندوز ۷ و ۸ پشتیبانی می‌کنند»؛ بنابراین ساختی که از Flutter 3.19.6 می‌آید روی
ویندوز ۸.۱ (و ۷) اجرا می‌شود، ولی محدودهٔ رسمی و تست‌شدهٔ این پروژه همان است که
شما خواستید: **ویندوز ۸.۱ تا ویندوز ۱۱**.

## ۴) ساخت روی کامپیوتر خودتان

نیازمندی‌ها: Flutter (برای اندروید نسخهٔ جدید، برای ویندوز `3.19.6`)،
Java 17+، Android SDK، و برای ویندوز Visual Studio 2022 با بارکاری C++.

```bash
flutter pub get
flutter analyze --no-fatal-infos --no-fatal-warnings
flutter test

# نسخه را مثل ورک‌فلو داخل pubspec.yaml بنویسید (اختیاری)
python3 tools/set_version.py 1.2.0+7

# اندروید
flutter build apk --release --build-name 1.2.0 --build-number 7 \
  --dart-define=TEL_APP_VERSION=1.2.0

# ویندوز (با Flutter 3.19.6)
flutter build windows --release --build-name 1.2.0 --build-number 7
```

### امضای حرفه‌ای APK (اختیاری)

به‌طور پیش‌فرض APK با کلید دیباگ امضا می‌شود؛ روی همهٔ گوشی‌ها **نصب می‌شود**
ولی برای Google Play باید کلید خودتان باشد. برای این کار:

```bash
keytool -genkey -v -keystore tel-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias tel
```

سپس فایل `android/key.properties` را بسازید:

```properties
storePassword=رمز-کیستور
keyPassword=رمز-کلید
keyAlias=tel
storeFile=/مسیر/کامل/tel-release.jks
```

از این پس هر ساخت APK با کلید شما امضا می‌شود (فایل‌های `key.properties` و
`*.jks` در `.gitignore` هستند و هرگز به گیت‌هاب نمی‌روند). برای استفاده در
ورک‌فلوی گیت‌هاب، محتوای کیستور را base64 کنید و در GitHub Secrets نگه دارید و
مرحلهٔ «آماده‌سازی کلید امضای APK» را ببینید؛ ورک‌فلو از قبل آماده است و
فقط باید Secretها را بسازید.

## ۵) ساختار پروژه

```
lib/
  main.dart                     نقطهٔ ورود، تم، زبان
  core/
    xml_document.dart           پارسر تلگرام + ویرایش دقیق بر اساس آفست + escape
    xml_validation.dart         بررسی سلامت فایل و قالب‌ها
    app_info.dart               نام/نسخه/لینک (از --dart-define ها)
  services/
    file_io_service.dart        خواندن/نوشتن فایل (اندروید: SAF، ویندوز: دیالوگ بومی)
    settings_store.dart         ذخیرهٔ تنظیمات کوچک (%APPDATA%\Tel\settings.json)
  state/editor_state.dart       وضعیت مرکزی (ChangeNotifier + AppScope)
  i18n/l10n.dart                متن‌های فارسی و انگلیسی
  i18n/localizations.dart       متن‌های آمادهٔ ویجت‌های Material برای فارسی
  ui/                           theme, widgets, home_screen و چهار پنل (تب)
android/                        پروژهٔ اندروید (Gradle Kotlin DSL, AGP 9.1.0, minSdk 24)
windows/                        پروژهٔ ویندوز (CMake + رانر C++, مانیفست ویندوز ۸.۱ تا ۱۱)
assets/                         فونت وزیرمتن، آیکن‌ها، فایل‌های نمونه
test/                           تست‌های واحد و تست رابط کاربری
tools/                          اسکریپت نسخه، اسکریپت نصب ویندوز، بررسی ایستای کد
.github/workflows/release.yml   ورک‌فلوی ساخت APK و EXE و انتشار
docs/                           راهنمای XML تلگرام + راهنمای ورک‌فلو
```

### تست و بررسی

```bash
flutter test                       # ۶ فایل تست: پارسر، اعتبارسنجی، فایل، زبان، ساختار، رابط کاربری
python3 tools/verify_sources.py    # بررسی ایستا (بدون نیاز به Flutter)
```

## ۶) سلب مسئولیت

* این برنامه فایل‌های **متنی XML** ترجمهٔ تلگرام را ویرایش می‌کند؛ خودِ برنامهٔ
  تلگرام را تغییر نمی‌دهد، به آن نفوذ نمی‌کند و از آن فایل APK نمی‌سازد. ساخت
  مجدد و امضای نسخهٔ تغییریافتهٔ تلگرام بر عهدهٔ خود کاربر است.
* «تلگرام» علامت تجاری شرکت Telegram FZ-LLC است و این پروژه هیچ وابستگی رسمی
  به آن ندارد.
* همیشه قبل از ویرایش، یک نسخهٔ پشتیبان از فایل خود نگه دارید (برنامه هم هیچ
  فایلی را بدون انتخاب شما بازنویسی نمی‌کند).
