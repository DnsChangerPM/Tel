# راهنمای کامل ویرایش متن‌های تلگرام (فایل‌های XML)

این سند همه‌چیزی را توضیح می‌دهد که برای ترجمهٔ متن‌های برنامهٔ تلگرام با
برنامهٔ **Tel** لازم است.

---

## ۱) فایل‌های متن تلگرام کجا هستند؟

متن‌های تلگرام (نسخهٔ اندروید) در پوشهٔ منابع پروژهٔ رسمی قرار دارند:

```
TMessagesProj/src/main/res/values/strings.xml          ← متن انگلیسی پایه
TMessagesProj/src/main/res/values/tg_inline_strings.xml ← متن‌های اینلاین پایه
TMessagesProj/src/main/res/values-fa/...                ← متن‌های فارسی
TMessagesProj/src/main/res/values-ru/...                ← متن‌های روسی
```

* برای هر زبان یک پوشه هست: `values-fa`، `values-ar`، `values-tr` و ...
* فایل مهم و حجیم اینلاین: **`tg_inline_strings.xml`**
* فایل کلیدهای عمومی برنامه: **`strings.xml`**

برای ترجمه، فایل انگلیسی را بردارید، در پوشهٔ زبان خودتان بگذارید و مقادیر را
ترجمه کنید. برنامهٔ **Tel** دقیقاً برای همین کار ساخته شده است.

> نام فایل دلخواه است؛ برنامه با هر فایل XML ای که تگ `<string>` داشته باشد کار
> می‌کند (نه فقط `tg_inline_strings.xml`).

---

## ۲) ساختار فایل

```xml
<?xml version="1.0" encoding="utf-8"?>
<resources>
    <!-- کامنت: توضیح برای مترجم‌ها -->
    <string name="ChatDelete">Delete</string>
    <string name="ChatForwardedFrom">Forwarded from %1$s</string>
    <string name="VoipGroupEnableAutoDelete">Auto-delete after %1$d days</string>
    <string name="VideoPlayerStreamingServer" translatable="false">tg://streaming</string>
</resources>
```

| بخش | معنی |
| --- | --- |
| `name="ChatDelete"` | **کلید** متن. هرگز آن را تغییر ندهید و ترجمه نکنید. |
| متن داخل تگ | **مقدار**؛ این همان چیزی است که برنامهٔ تلگرام نشان می‌دهد. |
| `translatable="false"` | این رشته ترجمه **نمی‌شود** (آدرس سرور، شناسه، ...). |
| `<!-- ... -->` | کامنت؛ برنامهٔ Tel آن را دست‌نخورده نگه می‌دارد. |

### قواعد مهم داخل مقدارها

| مورد | قاعده | نمونه |
| --- | --- | --- |
| خط جدید | کاراکترهای `\n` را حتماً نگه دارید | `خط اول\nخط دوم` |
| تب | `\t` را نگه دارید | `ستون۱\tستون۲` |
| جای‌گذاری | `%1$s`، `%2$d`، `%d`، `%s` دقیقاً مثل متن اصلی باشند | `%1$s پیام داد` |
| آکولاد | `{0}`، `{name}` را خراب نکنید | `سلام {name}` |
| علامت‌های ویژه | `&` باید `&amp;` باشد، `<` باید `&lt;` و `>` باید `&gt;` | `سلام &amp; خداحافظ` |
| نقل‌قول تک | در فایل‌های اندروید معمولاً `\'` نوشته می‌شود | `don\'t` |
| تگ‌های HTML | مثل `<b>`، `<a href="...">` با `&lt;`/`&gt;` نوشته می‌شوند | `&lt;b&gt;پریمیوم&lt;/b&gt;` |

⚠️ اگر `%1$s` را حذف کنید یا تعداد `\n` را عوض کنید، ممکن است متن در تلگرام
خراب نمایش داده شود یا برنامه خطا بدهد. تب **«بررسی سلامت»** فایل را از نظر
این قالب‌ها بررسی می‌کند: فایل انگلیسی همان بخش را به‌عنوان **مرجع** بارگذاری
کنید تا برنامه ناسازگاری‌ها را تیک‌بزن‌شده لیست کند.

## ۳) کار با برنامهٔ Tel، گام به گام

1. فایل XML را روی گوشی یا کامپیوتر خود کپی کنید.
2. برنامهٔ Tel را باز کنید.
3. **باز کردن فایل** را بزنید
   * اندروید: پنجرهٔ خود اندروید (SAF) باز می‌شود؛ هرجای حافظه را می‌توانید
     انتخاب کنید و **هیچ مجوز خاصی لازم نیست**.
   * ویندوز: دیالوگ «Open» ویندوز باز می‌شود (پوشهٔ پیش‌فرض: Downloads).
4. در تب **رشته‌ها**:
   * با فیلتر **ترجمه‌نشده‌ها** فقط متن‌هایی را ببینید که هنوز فارسی نشده‌اند.
   * هر متن را در کادر روبه‌روی آن ویرایش کنید. تغییرها فوراً ثبت می‌شوند ولی
     تا وقتی ذخیره نکنید، فایل روی دیسک دست‌نخورده است.
   * برگشت: دکمهٔ ↺ کنار هر رشته یا «برگشت همهٔ ویرایش‌ها».
5. تب **بررسی سلامت** را بزنید: خطاها (قرمز)، هشدارها (نارنجی) و اطلاعات.
6. **ذخیره** را بزنید (Android: انتخاب مقصد، Windows: ذخیره روی همان فایل یا
   «Save as»). خروجی UTF-8 بدون BOM است و فقط مقدار رشته‌های ویرایش‌شده در فایل
   تغییر می‌کند.

### میان‌برهای ویندوز

| کلید | کار |
| --- | --- |
| `Ctrl+O` | باز کردن فایل |
| `Ctrl+S` | ذخیره |
| `Ctrl+Shift+S` | ذخیره با نام جدید |
| `Ctrl+F` | رفتن به کادر جست‌وجو |

---

## ۴) استفاده از فایل ویرایش‌شده در پروژهٔ تلگرام

1. فایل ذخیره‌شده را در پوشهٔ زبان خود بگذارید:

   ```
   TMessagesProj/src/main/res/values-fa/tg_inline_strings.xml
   ```

2. بیلد بگیرید (Android Studio یا Gradle):

   ```bash
   ./gradlew :TMessagesProj:assembleAfatRelease
   ```

3. APK ساخته‌شده با کلید خودتان امضا می‌شود.

> اگر قصد تغییر دادن نسخهٔ نصب‌شدهٔ تلگرام روی گوشی را دارید، توجه کنید که
> بستهٔ تلگرام امضای مخصوص خودش را دارد و APK جدید باید با همان کلید (یا کلید
> دیگری که قبلاً نسخهٔ نصب‌شده با آن امضا شده) امضا شود، وگرنه اندروید اجازهٔ
> نصب روی آن را نمی‌دهد. برای اهداف آموزشی/محلی معمولاً نسخهٔ خودتان را جدا
> (`applicationId` متفاوت) و پاک‌نصب می‌کنید.

## ۵) پرسش‌های پرتکرار

**فایل من بزرگ است (چند صد کیلوبایت)؛ برنامه کند نمی‌شود؟**
پارسر برنامه یک‌بار روی هر تغییر متن اجرا می‌شود و شمارهٔ خط‌ها با جست‌وجوی
دودویی محاسبه می‌شود (نه پیمایش کامل برای هر رشته). ویرایش فایل‌های چند صد
کیلوبایتی روان است.

**کدگذاری فایل باید چه باشد؟**
UTF-8. اگر فایل UTF-16 باشد، برنامه خودش تشخیص می‌دهد و درست می‌خواند؛ ولی
همیشه با UTF-16 ذخیره می‌شود که توصیه نمی‌کنیم. خروجی Tel همیشه UTF-8 است.

**ساختار فایل من خراب شد، چه کنم؟**
تب «بررسی سلامت» تگ‌های نامتوازن و `&` بدون escape را نشان می‌دهد. قبل از
ویرایش، فایل اصلی را جای دیگری نگه دارید (برنامه بدون انتخاب شما هیچ فایلی را
بازنویسی نمی‌کند).

**فایل الان کجاست؟ روی اندروید مسیر دقیق را نشان نمی‌دهد.**
اندروید از سال ۱۰ به بعد اجازهٔ دسترسی به مسیر کامل را به برنامه‌ها نمی‌دهد؛
نام فایل در نوار بالا نمایش داده می‌شود و ذخیره با انتخاب خودتان در پنجرهٔ
اندروید انجام می‌شود.
